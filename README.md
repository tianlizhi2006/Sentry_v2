# 哨兵整车控制

工程基于 STM32H723 和 FreeRTOS，实现四全向轮底盘、双 Yaw 云台、Pitch 轴及发射机构的遥控控制。

## 控制链路

- UART5 接收 DR16 的 18 字节遥控帧，并解析摇杆、拨杆和键鼠字段；UART10 RX 另支持自定义键鼠帧。遥控输入决定底盘、云台和发射机构的模式与目标值。
- 底盘任务约每 2 ms 执行：模式判断 → 电机和惯导反馈更新 → 遥控速度及小陀螺目标计算 → 云台坐标转换 → 四轮逆运动学 → 3508 速度 PID → CAN2 电流指令。
- 云台任务每 1 ms 执行：电机与 IMU 反馈更新 → 模式判断 → 双 Yaw、Pitch 和发射机构控制 → 电流或力矩指令发送。遥控失联或无力模式下输出零指令。
- CAN1 接收功率板 `0x301` 数据，但底盘电流不经过功率预测或功率缩放，主控也不发送 `0x311` 限值指令。裁判系统尚未接入，发射热量许可当前固定允许。

## 底盘与小陀螺

- 左摇杆给出以云台为前方的平移速度；根据双 Yaw 的相对角度旋转到底盘坐标系。四轮目标速度依次为 `vy+r·wz`、`-vx+r·wz`、`-vy+r·wz`、`vx+r·wz`，其中 `r=0.25 m`。若任一轮超过 `MAX_WHEEL_SPEED`，四轮目标同比例缩放，再由各自的速度 PID 输出电流。
- 小陀螺使用固定 1.8 s 周期的分段摆线速度。每半周期令 `p(u)=(1-cos(2πu))/2`，前半周期为 `ωc+A·p(u)`，后半周期为 `ωc-(A/2)·p(u)`；`A=2(ωmax-ωmin)/3`，`ωc=ωmax-A`。当前未乘平移权重的范围为 5～7 rad/s，周期平均约 5.83 rad/s。
- 平移时旋转目标乘以 `clamp(1-(|chX|+|chY|)/1980, 1/3, 1)`；进入小陀螺时角速度按 6 rad/s² 限制上升。退出模式后重置摆线周期。

## 双 Yaw 云台与 Pitch

- 小 Yaw 使用 IMU 绝对角度、角速度串级 PID：角度环给出目标角速度，速度环给 GM6020 电流。相对机械偏角超过 1000 ECD 时冻结目标，回到 500 ECD 以内后恢复遥控目标累加。
- 大 Yaw 根据小 Yaw 相对机械偏角计算目标角速度，叠加底盘旋转前馈后由速度环给 DM4310 力矩，使小 Yaw 回到中位。
- Pitch 使用 IMU 角度、角速度串级 PID，输出 DM4310 力矩并叠加重力补偿。软限位为 -20°～30°；重新有力时以当前位置为目标，若已在限位外，只接受朝限位内的输入。
- 两个达妙电机在发送前检查使能状态；未使能时每 50 ms 尝试清错并重新使能，反馈确认前不发送力矩。

## 发射机构

- 两个摩擦轮目标转速分别为 ±6000 RPM；均进入目标 ±300 RPM 并稳定 100 ms 后锁存到速标志。发射请求、摩擦轮到速和拨弹电机反馈就绪后，拨弹盘以速度环正转，目标转子转速为 `10×60÷8×36=2700 RPM`。
- 拨弹盘正转起步 150 ms 后，若正向反馈转速连续低于 675 RPM 达 100 ms，则切换为 1350 RPM 反转。反转达到半个弹位（按 36:1、每圈 8 发计算为 18432 ECD）或满 300 ms 后停顿 50 ms，再恢复正转；持续发射期间可重复退弹。
- 反转仍使用拨弹速度环和原有 9000 电流指令上限。反馈短暂中断时不累计旧编码器角度，恢复后重新同步；反转最迟由 300 ms 超时结束。关闭发射或进入无力模式会取消退弹。

控制增益、方向、机械零点和限幅集中在 `App/Inc/app_preference.h`。

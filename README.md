# 哨兵遥控工程

本工程基于 STM32H723 和 FreeRTOS，用于哨兵底盘、双 Yaw 云台及发射机构的遥控控制。

## 控制与参数

- 小 Yaw 使用云台 IMU 角度、角速度串级闭环跟踪遥控目标；大 Yaw 根据小 Yaw 的相对机械偏角回中，并叠加底盘旋转速度前馈。
- PID、机械零点、遥控灵敏度和输出限幅集中在 `App/Inc/app_preference.h`，以当前源码中的实机参数为准。PID 的积分按控制周期累加，微分按相邻周期作差，不在内部乘除 dt。
- 大 Yaw 位置环输出上限为 30 rad/s，保持清理前实际生效的值；叠加底盘前馈后的速度目标仍限制在 DM 速度协议范围。速度环力矩上限保持当前配置的 5 N·m。
- 大 Yaw 位置环的积分分离阈值及积分输出限幅目前均为 0，因此位置积分仍不生效；这些设置按原值保留。
- 小 Yaw 相对偏角超过 1000 ECD（约 44°）时，将朝向目标冻结在当时的 IMU 角度，并暂停遥控目标累加。偏角回到 500 ECD（约 22°）以内后，从冻结目标继续接收遥控增量。
- 遥控异常、右拨杆下挡或云台必要反馈超时会停止输出；模式切换时重置目标和 PID 历史量。

已移除独立位置/速度调参模式、试验力矩前馈、临时限幅开关及 VOFA 发送。UART10 的原有接收配置继续保留。

## 已完成功能

- 四全向轮底盘：四个 3508 电机，CAN2，支持普通模式和小陀螺模式。
- 以云台朝向作为底盘前方，左摇杆控制前后、左右平移。
- 双 Yaw 云台：大 Yaw 为 DM4310，小 Yaw 为 GM6020，Pitch 为 DM4310。
- 云台 IMU 串级闭环、小 Yaw 软限位、大 Yaw 自动回中和底盘旋转前馈。
- 摩擦轮到速后允许拨弹，带电机反馈失联保护。
- CAN1、CAN2、CAN3 发送互斥，避免多个任务同时发送时覆盖帧 ID。

## 遥控方式

- 右拨杆下：整车无力。
- 右拨杆中：普通模式。
- 右拨杆上：小陀螺模式；双拨杆同时向上时为键盘普通模式。
- 键盘普通模式下：W 前进、S 后退、A 左移、D 右移。
- 键鼠模式下：C 键每按一次切换小陀螺；E 键每按一次切换整车无力。进入无力时小陀螺关闭，再按 E 恢复普通模式。
- 键鼠模式下：鼠标水平/竖直移动控制云台 Yaw/Pitch；F 键每按一次切换摩擦轮开关，按住鼠标左键请求发射。摩擦轮到速和电机反馈联锁仍然生效。
- 退出键鼠模式或遥控失联时，C/E/F 键的切换状态复位为关闭。鼠标灵敏度和单帧位移上限位于 `App/Inc/app_preference.h`。
- 普通模式下，左拨杆下：关闭发射机构。
- 普通模式下，左拨杆中：启动摩擦轮。
- 普通模式下，左拨杆上：保持摩擦轮运行，到速后启动拨弹。

## 验证

使用 Keil 的 `MDK-ARM/HAL_Robot.uvprojx` 构建固件。主机回归测试：

```text
python tests/run_gimbal_control_tests.py
```

该测试编译实际云台控制和 PID 源码，用模拟硬件依赖检查正常遥控、限幅、软限位滞回、反馈失联及发射联锁。它不代替实机稳定性验证。

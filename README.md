# 哨兵遥控工程

本工程基于 STM32H723 和 FreeRTOS，用于哨兵底盘、双 Yaw 云台及发射机构的遥控控制。

## 控制与参数

- 小 Yaw 使用云台 IMU 角度、角速度串级闭环跟踪遥控目标；大 Yaw 根据小 Yaw 的相对机械偏角回中，并叠加底盘旋转速度前馈。
- PID、机械零点、遥控灵敏度和输出限幅集中在 `App/Inc/app_preference.h`，以当前源码中的实机参数为准。PID 的积分按控制周期累加，微分按相邻周期作差，不在内部乘除 dt。
- 大 Yaw 位置环输出上限为 30 rad/s，保持清理前实际生效的值；叠加底盘前馈后的速度目标仍限制在 DM 速度协议范围。速度环力矩上限保持当前配置的 5 N·m。
- 大 Yaw 位置环的积分分离阈值及积分输出限幅目前均为 0，因此位置积分仍不生效；这些设置按原值保留。
- 小 Yaw 相对偏角超过 1000 ECD（约 44°）时，将朝向目标冻结在当时的 IMU 角度，并暂停遥控目标累加。偏角回到 500 ECD（约 22°）以内后，从冻结目标继续接收遥控增量。
- 遥控异常、右拨杆下挡或云台必要反馈超时会停止输出；模式切换时重置目标和 PID 历史量。

已移除独立位置/速度调参模式、试验力矩前馈及临时限幅开关。UART5 接收 DR16 的 18 字节帧，其中包含键鼠字段；UART10 RX 另保留自定义键鼠帧接收。

## 已完成功能

- 四全向轮底盘：四个 3508 电机，CAN2，支持普通模式和小陀螺模式。
- 小陀螺使用固定 1.8 s 周期的摆线角速度：前半周为基准速度加 `A` 波包，后半周为基准速度减 `A/2` 波包；未乘平移权重时范围为 3.5～6 rad/s。进入模式时按 6 rad/s² 限制角速度上升，退出模式时重置周期。双平移通道打满时旋转权重最低为 1/3，因此加权后的指令下限低于 3.5 rad/s。
- CAN1 只接收功率板的 `0x301` 回报。主控不发送 `0x311`，四轮电流不经过功率预测、功率反馈外环或功率缩放。
- 四轮速度 PID 输出仍受 `CHASSIS_3508_SPEED_PID_MAX_OUT` 限制，遥控速度目标仍受 `MAX_WHEEL_SPEED` 限制；两者是原有电机与速度上限。
- 以云台朝向作为底盘前方，左摇杆控制前后、左右平移。
- 双 Yaw 云台：大 Yaw 为 DM4310，小 Yaw 为 GM6020，Pitch 为 DM4310。
- 云台 IMU 串级闭环、小 Yaw 软限位、大 Yaw 自动回中和底盘旋转前馈。
- Pitch 在无力模式重新有力时以当前位置为目标；若当前位置超出 `-20°～30°`，只接受朝限位内的遥控/鼠标输入，并随向内移动收回目标，避免重新有力时突然回到边界。
- 大 Yaw 与 Pitch 两个达妙电机在每次云台发送前检查反馈 `state`；不是 1 时先发送清错、再发送使能，未恢复时每 50 ms 重试一次。反馈确认使能前，对应电机的 MIT 力矩指令为零。
- 摩擦轮到速且拨弹电机反馈正常后允许正转拨弹。拨弹盘起转 150 ms 后，若正向转速连续低于 675 RPM 达 100 ms，则反转，退回半个弹位或到达 300 ms 超时后停顿 50 ms，再正转重试；持续发射期间可重复退弹。已开始的反转不因电机反馈暂时中断而提前结束，但仍受 300 ms 超时约束；反转时沿用拨弹速度环的 9000 电流指令上限。
- CAN1、CAN2、CAN3 发送互斥，避免多个任务同时发送时覆盖帧 ID。

## 遥控方式

- 右拨杆下：整车无力。
- 右拨杆中：普通模式。
- 右拨杆上：小陀螺模式；双拨杆同时向上时为键盘普通模式。
- 键盘普通模式下：W 前进、S 后退、A 左移、D 右移。
- 键鼠模式下：C 键每按一次切换小陀螺；E 键每按一次切换整车无力。进入无力时小陀螺关闭，再按 E 恢复普通模式。
- 键鼠模式下：鼠标水平/竖直移动控制云台 Yaw/Pitch；F 键每按一次切换摩擦轮开关，按住鼠标左键请求发射。摩擦轮到速和电机反馈联锁仍然生效。
- 退出键鼠模式或遥控失联时，C/E/F 键的切换状态复位为关闭。鼠标灵敏度和单帧位移上限位于 `App/Inc/app_preference.h`。
- 普通模式下，左拨杆下：关闭发射机构。
- 普通模式下，左拨杆中：启动摩擦轮。
- 普通模式下，左拨杆上：保持摩擦轮运行，到速后启动拨弹。

## 验证

使用 Keil 的 `MDK-ARM/HAL_Robot.uvprojx` 构建固件。云台动作、限位和功率板通信需在实机上验证。

首次验证拨弹盘退弹时应确认反转方向、退回距离及电流上限是否适合实机。

小陀螺首次上板时应架空底盘，观察 `Chassis.Velocity.wz_set`：无平移输入且启动爬升结束后，目标按 1.8 s 周期依次经过约 4.33、6、4.33、3.5、4.33 rad/s；同时确认 `Motor[0..3].speed_set` 受 `MAX_WHEEL_SPEED` 限制。平移输入会将摆线目标乘以 1/3～1 的权重，实际角速度还受电机跟踪能力影响。

### 功率板首次通信检查

1. 架空底盘，保持右拨杆在无力挡，给主控和功率板上电。功率板接 CAN1：PD0 为 RX、PD1 为 TX；工程使用标准帧、经典 CAN、1 Mbps。检查 CAN_H/CAN_L、共地和总线终端电阻。
2. Keil 连接调试器并运行程序。在 Watch 窗口观察 `Message.PowerBoardFeedbackCount`：持续增长表示主控持续解析到板端 `0x301`；同时可查看 `Message.PowerBoardR.situation`、`Message.PowerBoardR.power` 和 `Message.PowerBoardR.power_limit`。
3. 用 CAN 分析仪确认板端 `0x301` 的实际发送间隔；当前主控不发送 `0x311`。若板端固件需要 `0x311` 才允许供电或周期回报，应按板端协议重新接入控制命令。
4. 轻推遥控并观察 `Chassis.Motor[0..3].give_current`。功率板反馈不会改变四轮电流指令；实测值只用于观察。
